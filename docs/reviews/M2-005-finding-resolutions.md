| R01 (Medium) — directory durability skipped on retry and at store creation | Every directory entry the store creates is made durable in its parent before the operation is acknowledged, and the sync is repeated on every attempt. `journal_store_t::open` syncs `root` in its parent when it creates `root`, and `root` when it creates `users`. `create_journal` syncs `users` after the user directory exists on **every** call, not only the one that created it (an earlier attempt may have created the directory and failed this sync), then writes and syncs the journal, then syncs the user directory.

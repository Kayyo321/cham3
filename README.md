# cham3
cham3 OS is a privacy focused debian based operating system designed for everyday use

## Development

Status: M0 repository and build baseline (in progress). M0 produces only a minimal Debian 13 live development image and the `cham3-base` skeleton package. It is not an installable or complete cham3 distribution, and a successful build or boot demonstrates no security property.

The only documented build host for M0 is Debian 13 (trixie) on x86-64. Build steps, limitations and sources are in [docs/engineering/developer_setup.md](docs/engineering/developer_setup.md). Verification results are recorded in the task handoff, not here.

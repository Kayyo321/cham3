# cham3
cham3 OS is a privacy focused debian based operating system designed for everyday use

## Development

The M0 repository and build baseline is documented in [docs/engineering/developer_setup.md](docs/engineering/developer_setup.md). M0 produces only a minimal Debian 13 live development image and the `cham3-base` skeleton package. It is not an installable or complete cham3 distribution, and a successful build or boot demonstrates no security property. The documented build host is Debian 13 (trixie) x86-64 only.
